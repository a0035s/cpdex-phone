# 本地 Codex 手機協作系統 PRD（PDR）

## 1. 背景與問題定義
目前 `codex.exe` 主要在本地桌面使用，使用者在移動場景下無法即時查看任務進度、介入進行中的工作、或持續同一條對話（thread）。

本專案要提供一個手機端入口，讓使用者可安全連線到本機 Codex，並在不改變主機帳號體系（host-follow）的前提下，完成任務監看、會話延續、以及執行中任務干預。

## 2. 產品目標
1. 讓手機可連線本地 `codex.exe` 並進行對話。
2. 支援跨網路遠端存取（非僅同 Wi-Fi/LAN）。
3. 手機端可上傳檔案與語音輸入。
4. 手機端可查看任務與會話全貌，並在任務執行中介入控制。
5. 確保安全驗證與單會話單飛（single-flight）鎖，避免衝突寫入。

## 3. 目標使用者與主要場景
- 目標使用者：已在桌面端使用 Codex 的單一帳號使用者。
- 核心場景：
  - 外出時查看任務數、任務列表與每任務 thread 數。
  - 進入指定任務查看 session/thread 列表，接續原對話。
  - 在任務執行中，從手機追加指令、調整方向、或停止當前回合。
  - 在既有任務下建立新 session 開始新分支。

## 4. 產品範圍
### 4.1 In Scope
- 手機連線本地 `codex.exe`（透過中介安全通道）。
- 跨網際網路遠端訪問。
- 手機文字對話、檔案上傳、語音輸入。
- 任務總覽、任務列表、每任務 thread/session 統計。
- 任務內 session 列表與選擇接續。
- 執行中任務干預（追加、改向、停止當前 turn）。
- 任務下建立新 session。
- 安全認證、授權、審計日誌。
- 每 session 單飛鎖（同時只允許一個寫操作流程）。

### 4.2 Out of Scope
- 手機端帳號註冊、切換、管理、多帳號控制。
- 脫離本地主機帳號體系的雲端獨立帳號系統。
- 多租戶企業權限模型（RBAC 細粒度先不做）。

## 5. 關鍵約束與假設
### 5.1 架構約束
1. 手機端僅控制「目前主機活躍帳號」（host-follow mode）。
2. `codex.exe` 仍為任務與 thread 的真實來源（source of truth）。
3. 行動端與主機端通訊需可穿越 NAT/防火牆（透過安全中繼或等效方案）。
4. 會話寫入採單飛鎖；衝突請求需返回可辨識狀態碼與可重試訊息。

### 5.2 產品假設
1. 使用者願意在主機首次配對手機並授權。
2. 手機端以低頻控制與監看為主，重度開發操作仍在桌面。
3. 語音可先轉文字再送入既有對話流程。

## 6. 功能需求（Functional Requirements）
- FR-01：手機可與本地主機上的 `codex.exe` 建立會話連線並發送/接收訊息。
- FR-02：系統支援遠端網際網路連線，不限制在同一 Wi-Fi。
- FR-03：手機端登入/配對後僅綁定並操作主機當前活躍帳號（不可切帳號）。
- FR-04：首頁顯示任務總數、進行中任務數、異常任務數（若有）與最近更新時間。
- FR-05：提供任務列表，至少含任務名稱、狀態、最後活動時間、session/thread 數量。
- FR-06：可進入任務查看其 session/thread 列表，顯示最後訊息摘要與時間。
- FR-07：可選擇任一既有 session/thread 並繼續對話。
- FR-08：可在任務下建立新 session/thread，並立即進入對話。
- FR-09：手機端支援檔案上傳到當前 session 作為上下文輸入。
- FR-10：手機端支援語音輸入，語音轉文字後可編輯再送出。
- FR-11：當任務回合執行中，手機可追加指令（append instructions）插入隊列。
- FR-12：當任務回合執行中，手機可發送改向指令（change direction），系統需標記來源與時間。
- FR-13：當任務回合執行中，手機可請求停止當前 turn（stop current turn），並回報最終狀態。
- FR-14：同一 session 在同一時刻僅允許一個寫入流程（single-flight lock）。
- FR-15：遇鎖衝突時，系統返回「已被占用」與重試建議，不得靜默覆蓋。
- FR-16：所有手機端關鍵操作（連線、追加、改向、停止、上傳）需可追蹤審計。

## 7. 非功能需求（Non-Functional Requirements）
### 7.1 安全（Security）
- NFR-SEC-01：行動端與中繼/主機通訊全程 TLS。
- NFR-SEC-02：首次配對需一次性驗證（例如短時效碼/掃碼），配對後使用可撤銷憑證。
- NFR-SEC-03：憑證需安全儲存（手機安全儲存區、主機加密存放）。
- NFR-SEC-04：敏感操作需具備抗重放機制（nonce/timestamp/signature 任一可行組合）。

### 7.2 可靠性（Reliability）
- NFR-REL-01：核心控制 API（查詢任務、發送訊息、停止 turn）月可用性目標 >= 99.5%。
- NFR-REL-02：網路短暫中斷可自動重連，重連後可恢復最近上下文。
- NFR-REL-03：single-flight lock 要有超時釋放與故障恢復機制，避免死鎖。

### 7.3 可觀測性（Observability）
- NFR-OBS-01：記錄請求 ID、task/session ID、操作類型、來源裝置、耗時、結果碼。
- NFR-OBS-02：提供基本運維指標：連線數、錯誤率、平均回應時間、鎖衝突率。
- NFR-OBS-03：關鍵失敗（認證失敗、停止失敗、檔案處理失敗）需可告警。

### 7.4 效能（Performance）
- NFR-PERF-01：任務列表 API 在 200 筆任務內，P95 回應時間 <= 1.5 秒。
- NFR-PERF-02：發送文字訊息到收到 ack，P95 <= 800 ms（不含模型生成時間）。
- NFR-PERF-03：停止當前 turn 請求在 P95 <= 2 秒內回覆是否已接受。

## 8. 使用者故事（User Stories）
1. 作為使用者，我在外面用手機也能查看目前所有任務與進度，判斷是否要介入。
2. 作為使用者，我想點進某任務的某個 thread，直接續聊，不需要重建上下文。
3. 作為使用者，我希望在任務跑偏時可以立刻從手機追加指令或改方向。
4. 作為使用者，我在發現任務失控時可以停止當前 turn，避免浪費時間與資源。
5. 作為使用者，我希望可用語音快速輸入想法，並能上傳檔案補充資訊。

## 9. 驗收標準與 UAT Checklist
### 9.1 驗收標準（Definition of Done）
- 所有 FR-01 ~ FR-16 皆有對應測試案例且通過。
- NFR 至少完成安全、可靠性、可觀測性、效能基線驗證。
- 主要流程（查看任務 → 進入 session → 對話 → 干預 → 停止）可穩定演示。

### 9.2 UAT Checklist
- [ ] 手機可完成首次配對並成功連到本地 `codex.exe`。
- [ ] 在不同網路（4G/5G）可成功訪問，不依賴同 Wi-Fi。
- [ ] 首頁正確顯示任務總覽統計。
- [ ] 任務列表可正確顯示每任務 session/thread 數。
- [ ] 任務內 session 列表可進入既有 thread 並接續對話。
- [ ] 可在任務下建立新 session 並立即發送訊息。
- [ ] 檔案上傳後可被當前 session 正常讀取/引用。
- [ ] 語音輸入可轉文字且可編輯後送出。
- [ ] 任務執行中可追加指令並被系統接收。
- [ ] 任務執行中可改向且結果可追蹤。
- [ ] 任務執行中可停止當前 turn 並回傳狀態。
- [ ] 併發寫入同 session 時會觸發 single-flight lock，無資料覆蓋。
- [ ] 審計日誌可查到關鍵操作紀錄。

## 10. 里程碑規劃
### 10.1 MVP（Phase 1）
- 目標：先打通「遠端可用 + 核心控制」。
- 範圍：FR-01~FR-08、FR-11~FR-15、NFR-SEC 基線、NFR-OBS-01。
- 交付：可遠端連線、任務與 session 管理、執行中干預、single-flight lock。

### 10.2 Phase 2
- 目標：提升輸入能力與運維成熟度。
- 範圍：FR-09、FR-10、FR-16；NFR-REL 全項、NFR-OBS 全項、NFR-PERF 優化。
- 交付：完整檔案/語音體驗、告警與指標面板、效能達標與穩定性提升。

## 11. 風險與緩解
1. 風險：遠端穿透方案在不同網路環境成功率不一。  
   緩解：預留多通道策略（中繼優先、直連回退）、連線診斷頁與自動重試。
2. 風險：手機干預與桌面操作同時進行造成狀態競爭。  
   緩解：single-flight lock + 明確操作序列號 + 衝突回應可重試。
3. 風險：停止 turn 不及時導致資源消耗。  
   緩解：停止請求高優先級通道，並在執行器側定期檢查 cancel token。
4. 風險：語音辨識錯字造成誤指令。  
   緩解：語音轉文字後預設進入可編輯確認步驟再送出。
5. 風險：安全設計不足導致遠端控制風險。  
   緩解：強制配對驗證、憑證撤銷、操作審計、異常登入告警。
